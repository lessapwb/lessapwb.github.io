## 🚀 Getting Started

### Add Your Photo

1. Add your professional photo to `assets/images/profile.jpg`
2. In `index.html`, replace the placeholder with:

```html
<img src="assets/images/profile.jpg" alt="Patrick Lessa" class="hero-image">
```

### Update the CV

Replace `assets/cv/Patrick_Lessa_CV.pdf` with the latest résumé. The hero "Download CV" button points to it.

### Deploy

The site is automatically deployed via GitHub Pages at `https://lessapwb.github.io`

## 🔧 Customization

### Changing Colors

Edit CSS variables in `assets/css/styles.css`:

```css
:root {
    --bg-primary: #0A192F;
    --accent-cyan: #00AEEF;
    --accent-neon: #00FFAF;
    /* ... */
}
```

### Adding Translations

Add new keys to both `lang/pt.json` and `lang/en.json`, then use in HTML:

```html
<span data-i18n-key="your-key">Default Text</span>
```
